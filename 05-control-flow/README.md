# Control Flow in Python: Conditionals and Loops

Companion code for the article *Control Flow in Python: Conditionals and Loops*.

## What this demonstrates

- `fizzbuzz.py` — `range()`, the modulo operator, and ordered `if / elif / else` branches.
- `guess_number.py` — a `while True` loop with `break`, `continue`, comparison operators, and truthiness-based input validation.

## Run it

```bash
python fizzbuzz.py
python guess_number.py
```

Requires Python 3.10 or newer. No external dependencies.

Part of the Python Fundamentals series on GeeksArray.
