# Variables, Numbers, and Types in Python

Companion code for the article *Variables, Numbers, and Types in Python*.

## What it demonstrates

- `variables.py` — assignment, dynamic typing, the core types (int, float, bool, None, str),
  checking types with `type()` and `isinstance()`, arithmetic operators (`//`, `%`, `**`),
  operator precedence, augmented assignment, type conversion, and the UPPER_CASE constant convention.
- `calculator.py` — a small interactive tip calculator that reads input, converts strings to
  numbers, does the arithmetic, and formats the result with f-strings.

## Run it

```bash
python variables.py
python calculator.py
```

Requires Python 3.10+. No external dependencies.
