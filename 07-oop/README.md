# Object-Oriented Programming in Python

Companion code for the article *Object-Oriented Programming in Python*.

## What this demonstrates

- `bank_account.py` — defining a class, `__init__` and instance attributes, methods and `self`, a shared class attribute, encapsulation with a leading underscore (and a read-only `property`), plus `__str__` and `__repr__`.
- `shapes.py` — a base `Shape` class with two subclasses (`Circle`, `Rectangle`) showing inheritance, `super()`, method overriding and polymorphism, and a `@dataclass` example.

## Run it

```bash
python bank_account.py
python shapes.py
```

Both files run on Python 3.10+ with no external dependencies.
