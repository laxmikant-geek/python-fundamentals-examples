# Python Collections: Lists, Tuples, Sets, and Dictionaries

Companion code for Part 4 of the Python Fundamentals series.

## What this demonstrates

- `collections_demo.py` — creating and mutating lists (index, slice, append/insert/remove/pop, sort/sorted, comprehensions), tuple unpacking, set operations (union/intersection/difference, membership), dictionary access with `[]` vs `.get()`, updating, iterating `.items()`, a dict comprehension, and nesting collections.
- `word_count.py` — a worked example that counts word frequencies with a dictionary.

## Run it

```bash
python collections_demo.py
python word_count.py
```

No external dependencies. Requires Python 3.10+.
