# Functions in Python: Arguments, Return Values, and Scope

Companion code for the GeeksArray article on Python functions.

## What this demonstrates

- `functions_demo.py` — defining functions with `def`, parameters vs arguments,
  return values, returning a tuple, default and keyword arguments, and a gentle
  intro to `*args` and `**kwargs`, plus docstrings and type hints.
- `temperature.py` — small, pure functions: a temperature converter and a
  discount/tax calculator refactored into named helpers.

## Run it

```bash
python functions_demo.py
python temperature.py
```

Requires Python 3.10+.

Part of the Python Fundamentals series on GeeksArray.
