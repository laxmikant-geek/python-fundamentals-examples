# Working with Strings and Text in Python

Companion code for the article *Working with Strings and Text in Python* (Post 3 of the Python Fundamentals series).

## What it demonstrates

- `strings_basics.py` — quote styles and escape sequences, multiline strings, indexing and slicing, immutability, common methods (`upper`, `strip`, `split`, `join`, `replace`, `find`, `startswith`, `count`), membership with `in`, `len()`, f-strings and format specifiers, concatenation and repetition.
- `text_report.py` — a small worked example that parses messy comma-separated input, cleans each field, and prints an aligned report table using f-string format specifiers.

## Run it

```bash
python strings_basics.py
python text_report.py
```

Requires Python 3.10+. No external dependencies.
