# 01 — Getting Started with Python

Companion code for the article *Getting Started with Python: Install, Run, and Your First Program*.

## What it demonstrates

- `hello.py` — the classic first program using `print()`.
- `greet.py` — reading user input with `input()` and building a message with an f-string.

## Run it

```bash
python hello.py
python greet.py
```

Use `python3` instead of `python` on macOS/Linux if needed. Requires Python 3.10+.

Part of the Python Fundamentals series on GeeksArray.
